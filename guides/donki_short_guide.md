# 編集の手引き: ドン・キホーテ 商品紹介ショート（初版）

Claude がこの手引きを読み、字コンテと素材から編集の判断をする。作ったら「採点表」で自分の出来を採点し、直してから人に見せる。

- 根拠: @donki_cp の人が編集した完成版8本の分析（`guides/research/donki_cp_videos.md`、2026-11-06）。数値は8本の実測の範囲
- 評価用に取ってある動画（魚が焼けルンルン、7693465337785830677）は、手引きの根拠に使っていない。この手引きを直すときも見ない

## 1. 目指す仕上がり

見る人が最初の1秒で手を止め、10〜18秒のあいだ一度も退屈せずに、「何ができる商品か」「使うのは簡単か」を理解して、詳細を見にいく動画。

## 2. 判断の原則（理由つき）

### 2-1. つかみ（0〜2秒）

- **0秒の画は、完成形か、実演の最中の手元にする。** 箱や空の容器から始めない。最初の1コマで「何か起きている」と分からないと、指が止まらない（8本すべて）
- **声とテロップも0秒から出す。** 冒頭の無音は離脱の理由になる（8本すべて、0.3秒時点で音が出ている）
- **最初の一言は、次の型から1つ選ぶ。** 困りごとの問いかけ（「〜ことない？」）、対象者への呼びかけ（「〜気になってた方へ」）、数値（「秒速50m！」）、内緒話（「大きな声で言えないのですが」）、一番の長所、常識を覆す一言。字コンテに冒頭の型の指定があれば、それに従う

### 2-2. 台本

- **字コンテは意図として扱い、短尺で伝わる文に書き直してよい。** 字コンテに「編集状況に応じて多少変更する場合があります」とある。変えてよいのは言い回し・順番・情報の足し引き。変えないのは、商品の訴求点と、字コンテが決めた冒頭の型と締めの形
- **実演は手順の順に並べ、1手順に1カット・1句を当てる。** 「入れて → 温めて → 完成」と見る人が頭の中で再現できる順番にする（8本中6本）
- **具体的な事実を入れる。** 素材に映っている数字（ワット数・時間・枚数・サイズ）や、箱に印刷された機能は、ぼんやりした形容詞より強い。ただし素材か箱で確かめた事実だけを書き、推測で数字を作らない
- **「〜するだけ」で手軽さを言う。** 手順が短いことがそのまま長所になる（2・5・8）
- **使い道は場面や食材を替えて並べる。** 1つの使い道だけだと「自分には関係ない」と思われる（2・3・4・6）
- **1文を、テロップ1行ぶんの句（4〜12字、多くは6〜10字）に分ける。** script.json の `phrases` に句を書く
- **締めは、商品名の画面のあとに問いかけを1つ置く**（「あなたなら何〜？」など）。最近の投稿（5〜8）はこの形

### 2-3. 声のテンポ

- **句と句の間をほとんど空けない。** 文の間は0〜0.1秒にする。8本とも、0.3秒以上続く無音はなかった
- **話す速さは毎秒8〜10かな文字を目安にする**（8本の推測値8.2〜10.5）。Fish Audio の speed で調整し、review.py の「話す速さ」で確かめる
- **全体の尺は10〜18秒に収める。** 収まらないときは、句を削る（速さを上げすぎて聞き取れなくしない）

### 2-4. カット

- **カットは動作の区切りで替え、平均1.2〜2.0秒にする。** 3秒を超えるカットは、実演の見せ場など理由があるときだけ（8本で4つ）
- **0.4〜0.6秒の短いカットは、場所の切り替えや小さな動作に使う。** つなぎを速く見せる
- **カットとテロップの切り替えは揃えなくてよい。** テロップは声の句に合わせ、カットは動作に合わせる。1カットに2〜3枚のテロップが出てもよい
- **同じ素材の同じ区間を2回使わない。** まだ使っていない使用シーンを優先する
- **声と画を合わせる。** 声で特定の商品や機能（「煮込み料理や」「ホットサンドも」）を言っている間は、その商品か機能が分かる画を出す。その使用シーンの素材がなければ、その商品の箱（パッケージ）を見せる。声と関係のない使用シーンでつながない（依頼者の方針、2026-11-09。人の完成版もこの形）
- **字コンテの映像指示に合う素材がなく、声も特定の商品を指していないとき**は、同じ商品のまだ使っていない使用シーンで置き換える

### 2-5. テロップ

- **1画面に1行だけ、句ごとに約1秒で替える。** 白い太ゴシック、細い黒縁、縦は画面の上から約48〜52%（8本すべて）。build_b.py の `captions: "phrase"` と `caption_style.center_y`（1920の約50% = 960前後）で作る
- **つかみのテロップだけを大きくする**（2・3・5・6・8）。今の道具では句ごとの大きさを変えられないので、Premiere で付ける（下の「道具でまだできないこと」）
- **強調は大きさで行う。** 色の強調はシリーズ物だけ

### 2-6. 商品名と常時表示（ドンキの決まり）

- **商品名は、パッケージの画面で1回だけ大きく出す。** 後半（全長の60〜90%）に置き、1〜3秒見せる。その画面の下に「※詳細は👇をチェック」
- **左下に、商品名と「※詳細は👇をチェック」を常に出す。** 価格は画面に出さず、説明文に書く
- 常時表示とロゴは、依頼者の素材（アイコン画像）が必要。今は Premiere で付ける

## 3. 作り方（道具の使い方）

1. 字コンテ（`jikonte_pptx.py` / `jikonte_parse.py`）と素材の記録（`shots.py` → `shots.json` の segments）を読む
2. 2章の原則で台本を書き直し、`script.json` に文と `phrases`（句）と `yomi` を書く。`speed` は1.3前後から、`gap_sec` は0.05、`lead_in_sec` は0
3. `narrate.py` で生成し、句ごとの時刻（narration.json の phrases）を得る
4. `cutlist.json` を書く: `captions: "phrase"`、`caption_style: {"center_y": 960}`、`lead_sec: 0.05`、`tail_sec: 0.3`。カットは `at` に句（例 `L02.1`）を指定し、動作の区切りに合わせて素材を割り当てる
5. `build_b.py` で書き出し、`review.py` で検品材料を作る
6. 4章の採点表で採点し、14点未満または0点の項目があれば直して、5に戻る（最大3回）

## 4. 採点表（自己検品）

review.jpg（各カットのコマ）、review.json（数値）、プレビューの文字起こしを見て、各項目を 0 / 1 / 2 点で付ける。合計16点満点、14点以上かつ0点の項目なしで合格。

| # | 項目 | 2点 | 1点 | 0点 |
|---|---|---|---|---|
| 1 | つかみの画 | 0秒が完成形か実演の手元 | 0秒は商品だが動きがない | 箱・空の容器・無関係な画 |
| 2 | つかみの言葉 | 2-1の型のどれかで、0秒から声とテロップ | 型はあるが0.3秒以上遅れる | 型がない／説明から入る |
| 3 | 尺 | 10〜18秒 | 18〜22秒 | それ以外 |
| 4 | 声のテンポ | 毎秒8〜10.5かな、文の間の最長0.15秒以下 | どちらか一方だけ満たす | どちらも満たさない |
| 5 | カットの長さ | 平均1.2〜2.0秒、3秒超えは理由のある1つまで | 平均2.0〜2.6秒 | 平均2.6秒超 |
| 6 | 手順と具体性 | 手順の順に1手順1カット、素材で確かめた数字か機能が入っている | どちらか一方 | どちらもない |
| 7 | テロップ | 1行・句単位・4〜12字・縦中央 | 2行が混ざる／13〜16字がある | 文単位で長い／3行以上 |
| 8 | 商品名と締め | 後半に商品名の画面、最後に問いかけ（または字コンテ指定の締め） | どちらか一方 | どちらもない |

採点の結果は `review_score.md` に、項目ごとの点と理由、次に直すことを書いて残す。

## 5. 道具でまだできないこと（Premiere で人が付ける）

- つかみのテロップだけ大きくする（句ごとの大きさ指定）
- 左下の常時表示、右上のロゴ、商品名画面の大きなテロップ
- BGM・効果音（8本では BGM は無いか、ごく小さいと推測されている）
- 素材の早回し・ズーム
